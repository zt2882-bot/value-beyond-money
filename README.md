## 货币不是价值的唯一尺度 · Money Is Not the Only Measure of Value

现代经济闲置着五样东西——**产能、土地、资源、劳动力、时间**。机器停转、耕地撂荒、楼房空置、人失业、每个人的闲暇时间被刷走。

Modern economies leave five things idle — **capacity, land, resources, labor, and time**. Machines idle, farmland abandoned, buildings vacant, people unemployed, and everyone's leisure time swallowed by feeds.

这五重闲置的根源，不是"钱不够"，而是**"以货币为唯一价值尺度"**——在货币的尺度下，过剩的产能"没有价值"、闲置的土地"没有价值"、失业者的时间"没有价值"。

The root of this five-fold idleness is not "not enough money," but **"money as the only measure of value"** — under money's measure, surplus capacity is "worthless," idle land is "worthless," and an unemployed person's time is "worthless."

1980 年，时间银行创始人 Edgar S. Cahn 说过一句至今无人超越的话：

In 1980, Time Banking founder Edgar S. Cahn said something no one has surpassed:

> **"We refused to give money a monopoly on the definition of value."**
> （我们拒绝给货币对"价值定义"的垄断权。）

本报告做的，就是这件事：**建立一套不以货币为唯一尺度的交换机制**，让"劳动"与"时间"——这些被货币尺度判为"无价值"的东西——重新进入价值循环。

That is exactly what this report does: **build an exchange mechanism that does not take money as the only measure**, letting "labor" and "time" — things money's measure judges "worthless" — re-enter the value cycle.

## 一个提醒 · A Note

这不是政治经济学批判，也不是意识形态宣言。这是一份**系统设计文档**——它不站队，只描述"如何让被货币尺度判为无价值的东西，重新进入价值循环"的工程路径。

This is neither a critique of political economy nor an ideological manifesto. It is a **system design document** — it takes no side, and only describes the engineering path of "letting what money's measure judges worthless re-enter the value cycle."
